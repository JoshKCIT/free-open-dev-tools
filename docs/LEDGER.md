## How to pick this up

```sh
pnpm install
node scripts/new-tool.mjs <id>     # from the table above
# write src/index.ts, src/meta.json and test/
pnpm sync && pnpm verify
# then add apps/web/src/tools/<id>.ts and run pnpm e2e
```

`CONTRIBUTING.md` has the rules each tool has to satisfy. They are all enforced by `pnpm verify`, so nothing depends on remembering them.
